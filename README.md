# Java Airline Management System

## Overview
This is a Java Swing-based Airline Management System that simulates real-world airline operations such as passenger registration, flight search, ticket booking, and ticket management.

The system is built using object-oriented programming principles and provides an interactive multi-tab GUI for managing airline data.

---

## Features

- Passenger registration with validation  
- Flight search based on source and destination  
- Ticket booking with seat availability tracking  
- Ticket cancellation functionality  
- Real-time flight availability display  
- Ticket management with booking details  
- GUI-based interaction using tabbed interface  

---

## System Modules

### 1. Passenger Management
- Register passengers with name and passport number  
- Prevents duplicate passport entries  

### 2. Flight Management
- Predefined flights with routes and seat availability  
- Displays available flights dynamically  

### 3. Flight Search
- Search flights based on source and destination  
- Displays matching flights  

### 4. Ticket Booking
- Select passenger and flight  
- Books ticket if seats are available  
- Generates unique ticket number  
- Stores booking date  

### 5. Ticket Management
- View all booked tickets  
- Cancel selected tickets  
- Updates seat availability

## Tech Stack

- Java

## Classes Used

- Passenger → stores passenger details  
- Flight → manages flight data and seat availability  
- Ticket → stores booking details

## How to Run

1. Compile the program:
javac AirlineManagementGUI.java

2. Run the application:
java AirlineManagementGUI
